# Структура тестов

Тесты разделены по уровню проверки:

- `api/` - проверки FastAPI-эндпоинтов через ASGI-клиент.
- `api/rate_limit/` - проверки rate limit на уровне API-эндпоинтов.
- `component/` - проверки отдельных компонентов в окружении фреймворка без полных пользовательских сценариев.
- `integration/` - проверки repositories и services на реальной test DB без HTTP-слоя.
- `unit/` - изолированные проверки схем, helpers и доменной логики без состояния базы данных.
- `helpers/` - общие утилиты для API- и DB-тестов.

Для чистых unit-тестов указывайте `pytestmark = pytest.mark.no_db`, чтобы пропустить автоматическую очистку базы.
